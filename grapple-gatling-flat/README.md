# Grapple Gatling

Files: Dockerfile, server.js, index.html, package.json, render.yaml. Everything sits at the top level, no folders.

Upload these files to a GitHub repository (Add file > Upload files, drag the files in, Commit), then on Render:
New > Web Service > pick the repository > Free > Create. Render builds from the Dockerfile and gives you a
https://<name>.onrender.com link. The free plan sleeps after about 15 minutes idle and takes up to a minute to wake.

Controls: A/D move, W or Space jump, left click shoot, F hook (hold F to reel in), E let go, Esc menu.
